Fourward MCP server

Run our free AI visibility check and AI crawler checker from Claude, ChatGPT, Cursor or VS Code. Ask "how AI-ready is hubspot.com?" and get the score in the chat. No sign-up, no API key.

https://www.fourwardhq.com/mcp

Remote MCP server over HTTP. Read-only: it checks public pages and never changes anything. We don't log requests. Privacy policy.

Two tools

ToolWhat it doesAsk it
check_ai_visibilityScores a website out of 100 on 30 checks: AI crawler access, homepage signals, structured data, entity and authority, and AI-ready content."How AI-ready is hubspot.com?"
check_ai_crawlersShows which of 20 AI crawlers can read the homepage, from robots.txt rules to a firewall test, plus llms.txt and sitemap lines."Can ChatGPT and Claude crawl notion.com?"

Both tools return the same results as the AI visibility check and the AI crawler checker on this site. They list problems and scores, not fixes.

Claude

  1. Open Settings, then Connectors.
  2. Choose Add custom connector.
  3. Name it Fourward and paste https://www.fourwardhq.com/mcp.
  4. Leave sign-in off, then select Add.

Claude Code

  1. Run this in your terminal:
claude mcp add --transport http fourward https://www.fourwardhq.com/mcp

ChatGPT

  1. In Settings, open Apps, then Advanced settings, and turn on Developer mode.
  2. Create a new app with the URL https://www.fourwardhq.com/mcp and no authentication.
  3. In a chat, pick it from the + menu.

Cursor

  1. Add this to .cursor/mcp.json:
{
  "mcpServers": {
    "fourward": {
      "url": "https://www.fourwardhq.com/mcp"
    }
  }
}

VS Code

  1. Add this to .vscode/mcp.json:
{
  "servers": {
    "fourward": {
      "type": "http",
      "url": "https://www.fourwardhq.com/mcp"
    }
  }
}

Frequently asked questions

What is an MCP server?

MCP, the Model Context Protocol, is an open standard that lets AI assistants use outside tools. Once you add Fourward's MCP server, Claude, ChatGPT and other assistants can run our checks when you ask them to.

Is the Fourward MCP server free?

Yes. It is free, needs no account and no API key. It runs the same free checks as the tools on our website.

Which tools does it include?

Two: check_ai_visibility, which scores a site out of 100 across 30 checks, and check_ai_crawlers, which shows which of 20 AI crawlers can read a site.

Does it fix anything on my site?

No. Both tools only read public pages, robots.txt, sitemaps and public knowledge sources. They list problems and scores. We cover the fixes in a free audit.

What do you store?

Nothing about your requests. We do not log MCP calls or receive your conversation. The public result for each domain is cached for up to 12 hours so repeat checks are fast. Our privacy policy has the details.

Which apps can use it?

Any app that supports remote MCP servers over HTTP, including Claude, Claude Code, ChatGPT in developer mode, Cursor and VS Code.
